## Documentation

For any task that creates, edits, moves, splits, or deletes files under
`docs/` or any `README.md`, load the `diataxis` skill
(`skills/diataxis/SKILL.md`) and follow it. Print its Quadrant Classification
Receipt before the first write to each asset, then run its strict audit on
every touched file. The docs here follow Diátaxis quadrants, and the receipt
plus audit keep tutorials, how-to guides, reference, and explanation from
bleeding together. README structure, tone, and gates stay with
`readme-standard`. Test fixtures under `skills/*/tests/fixtures/` are test
data, not documentation, and are exempt.
